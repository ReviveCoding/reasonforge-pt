# Limitations

- Three seeds limit population inference; the 450 locked cells repeat 150 examples.
- The primary interval includes zero and the +0.03 promotion gate failed. RCAC superiority is not established.
- Public-benchmark pretraining contamination cannot be excluded.
- Post-final routing, slicing, robustness, uncertainty, and systems analyses are exploratory or diagnostic, not primary promotion evidence.
- Completion length and failure categories are post-outcome descriptive slices, not routing predictors or confirmatory subgroups.
- The available uncertainty proxies support association with verifier outcomes. They are not calibrated real-world, safety, or production confidence probabilities.
- Mean token entropy was unavailable; sequence log probability had partial coverage.
- D115R device telemetry describes one replay environment. Timestamp-integrated energy is estimated from sampled power; device-active GPU time was not directly measured.
- Human-review labels are pending and did not inform the scientific decision.
- Public GPU reproduction is incomplete without licensed data, model access, adapters, runtime manifests, and qualified hardware. The portable CI suite checks only exported code and aggregate artifacts.
